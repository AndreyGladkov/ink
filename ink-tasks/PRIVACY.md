# Privacy

Ink Tasks does not connect to the internet. The only permission it asks for is to show notifications, for reminders; to show them on time it also sets alarms and starts again after the phone restarts, which Android allows without asking. Tasks are kept in Markdown files: in the app's private storage on the device, which is not backed up, or in the one folder you choose in the system picker, which the app can then read and write and nothing else. What happens to that folder afterwards, for example syncing it with Obsidian Sync, is up to the apps you use for it. Another app can read the open tasks that have a due date, their list and reminder time only after you allow it the permission "Ink Tasks tasks"; Ink Calendar asks for it to show them, and no app can change tasks this way. The settings are kept in the app's private storage.

# Конфиденциальность

Ink Tasks не подключается к интернету. Из разрешений приложение просит только показ уведомлений, для напоминаний; чтобы показать их вовремя, оно ставит будильники и запускается после перезагрузки телефона — на это Android разрешения не спрашивает. Задачи хранятся в md-файлах: в закрытом хранилище приложения на устройстве, которое не попадает в резервные копии, или в одной папке, которую вы выбираете через системный выбор папки, — приложение может читать и записывать только её. Что дальше происходит с этой папкой, например синхронизация через Obsidian Sync, решают приложения, которыми вы для этого пользуетесь. Другое приложение может прочитать невыполненные задачи со сроком, их список и время напоминания, только если вы дадите ему разрешение «Задачи Ink Tasks»; его просит Ink Calendar, чтобы их показывать, а менять задачи так нельзя. Настройки хранятся в закрытом хранилище приложения.
