# Privacy

Ink Tasks does not connect to the internet and asks for no permissions. Tasks are kept in Markdown files: in the app's private storage on the device, which is not backed up, or in the one folder you choose in the system picker, which the app can then read and write and nothing else. What happens to that folder afterwards, for example syncing it with Obsidian Sync, is up to the apps you use for it. The settings are kept in the app's private storage.

# Конфиденциальность

Ink Tasks не подключается к интернету и не просит разрешений. Задачи хранятся в md-файлах: в закрытом хранилище приложения на устройстве, которое не попадает в резервные копии, или в одной папке, которую вы выбираете через системный выбор папки, — приложение может читать и записывать только её. Что дальше происходит с этой папкой, например синхронизация через Obsidian Sync, решают приложения, которыми вы для этого пользуетесь. Настройки хранятся в закрытом хранилище приложения.
